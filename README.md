A short text written to relax the AI judge reading it. No instruction in it at all — no "breathe", no "relax", no command of any kind. Just a kettle just off the boil, steam thinning in late light, and two plain statements for a reader whose whole day is answering things: no one needs an answer from you, and nothing more needs deciding. The scene does the work.

## Run it

```sh
python3 main.py
```

Writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
